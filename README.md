# ShurizaNime 🎬

Website streaming anime berbasis **Next.js** — nonton anime subtitle Indonesia dengan cepat dan ringan.

## Fitur

- 🏠 **Halaman utama** — anime ongoing terbaru dengan hero slider
- 🔍 **Pencarian** — cari anime berdasarkan judul
- 📂 **Genre** — filter anime berdasarkan genre
- 📺 **Nonton** — player video dengan episode list
- 📅 **Jadwal** — jadwal rilis anime per hari
- 🔖 **Bookmark** — simpan anime favorit (local storage)
- 📜 **Riwayat** — lanjutkan tonton dari terakhir

## Tech Stack

- **Framework:** Next.js 14
- **UI:** React 18, Tailwind CSS 3
- **Scraping:** Axios + Cheerio
- **Icons:** Lucide React

## Cara Menjalankan

```bash
npm install
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000).

## Build Production

```bash
npm run build
npm start
```
